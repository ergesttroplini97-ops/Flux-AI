## Le cinque regole che non si negoziano

1. **Nessun segreto nel repository** — è pubblico. Chiavi e token nelle
   variabili d'ambiente di Vercel, mai nel codice, mai negli URL dei remote.
2. **Niente API di Notion dal browser.** L'unico punto di scrittura verso il
   CRM è una funzione serverless.
3. **Nessun dato commerciale in chiaro qui dentro.** Fatturato, nomi clienti e
   valutazioni interne stanno su Notion e nel vault privato.
4. **Niente di nuovo finché l'ultimo costruito non è in produzione.**
5. Nessun framework, nessuna compilazione: HTML, CSS e JavaScript a mano.
